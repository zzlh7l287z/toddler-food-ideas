# 怀孕后HCG和孕酮多少才正常，HCG一定要达到十万以上才可以吗？

> 更新时间：2026-09-16 (UTC+8)

妊娠早期，去医院检查的两个血值就是孕酮和HCG，医生也是非常看重这两个数值的变化。

那么这两种激素在**各个时期的正常值**是多少呢？**HCG一定要达到十万以上才可以吗？**如何判断是否有异常？

**何为HCG？**

受精卵着床后，胎盘合体滋养层细胞产生大量的人绒毛膜促性腺激素，可通过孕妇血液循环而排泄到尿中。

妊娠早期，血清和尿中的HCG水平即可迅速升高，孕期第8-10周达到高峰，之后逐渐下降，至孕期第4个月始降至中等水平，并一直维持到妊娠末期。

一般来说，正常人的β-HCG小于3.1IU/L，如果**超过5就考虑妊娠可能，超过10基本可以确定妊娠。**

**‼️注意：**

- 
HCG正常值因人而异，所以**不要去跟别人作对比**，如果过度紧张影响到宝宝就不好了。

- 
关注HCG相对变化情况；如果HCG停止隔天加倍，可能有异常。

- 
**HCG有异常还需要结合其他检查**，查明情况才能确定到底该怎么治疗。

**何为孕酮？**

孕酮是由卵巢黄体和胎盘分泌的一种天然孕激素，也是我们平时说的黄体酮，能够保护子宫内膜，维持整个妊娠过程。

孕酮**有利于受精卵着床**，保证胎儿的安全生长。另外还能**促进乳腺的发育**，为分泌乳汁做准备。

**‼️注意：**

- 
正常妊娠孕激素水平波动范围很大（其实**同一个人同一天两次检测都可能有很大差别**）。

- 
孕激素水平低更多是胚胎发育不良的结果，而不是流产的原因。

**写在最后：**

孕早期反复**检查HCG与孕酮，只可大致预测胚胎发育情况**。因此，不管是生化妊娠，早期流产还是异位妊娠，**都不是单纯凭着HCG的翻倍以及孕酮的高低进行诊断的**，还有其他辅助检查来进行综合分析，才能进行相应处理。
